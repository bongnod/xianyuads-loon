# 闲鱼 Loon 去广告与日志拦截

版本：1.1.0（2026-10-30）。基于两次 HAR（257 条、215 条）核对，保留原有四条广告规则，补充三条日志路径规则。

## 对比结果

原广告规则匹配第一次 12 条、第二次 1 条请求。其中 alimama_tuijian.mp4 广告视频为 9 条、1 条；三个广告域名第一次各 1 条，第二次未出现。未发现第二次抓包中原广告规则遗漏的新广告端点。请求未出现不能证明已成功拦截。

新增日志规则匹配第一次 11 条、第二次 15 条，覆盖支付日志、播放器日志和高德日志。日志不是广告；共享服务规则也会影响其他阿里系应用。

第二次新增的调度、风控和普通视频端点没有充分广告依据，未加入拦截。没有足够的首页业务 JSON 响应来验证信息流广告清理。

## 安装

Loon → 插件 → 添加远程插件：

`https://raw.githubusercontent.com/bongnod/xianyuads-loon/main/XianyuAds.plugin`

当前仓库为私有仓库，Loon 无法依赖浏览器登录读取上述地址；请下载插件后本地导入，或使用你已配置的私有订阅方式。不要在订阅 URL 中放 GitHub 令牌。

启用 HTTPS 解密并信任 Loon 证书后，HTTPS 路径规则才能生效；插件已列出对应 MITM 主机名。
